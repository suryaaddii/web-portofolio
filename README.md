
# Personal Developer Portfolio

A modern, responsive personal portfolio website showcasing my professional experience, technical skills, selected projects, education, and certifications as a Fullstack Software Developer.

## Live Website

**[suryaaddii.vercel.app](https://suryaaddii.vercel.app)**

## Overview

This portfolio is designed to present my professional background and software development experience, with a focus on backend development, fullstack web applications, IoT, and system integration.

The website features a clean, minimal interface with reusable components and responsive layouts.

## Features

- Professional profile and introduction
- Technical skills and technology stack
- Professional experience timeline
- Featured project showcase
- Education and certifications
- Downloadable curriculum vitae
- Contact and professional social links
- Responsive desktop and mobile layouts
- Animated user interface
- SEO metadata configuration

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/suryaaddii/web-portofolio.git
```

Navigate to the project directory:

```bash
cd web-portofolio
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```

## Deployment

The application is hosted on Vercel.
